# Archived stock Maxwell firmware (v1.0.1.22 – v1.0.1.46)

Unmodified stock images for the original Audeze Maxwell, downloaded on 2026-11-27 from Audeze's own firmware server (`https://audeze-maxwell.s3.amazonaws.com/FW_v1_0_1_<N>/`). They're kept here so they stay available if that server is ever locked down.

**These are untested.** They're early launch-era builds, and very old firmware may not pair well with newer dongle firmware. They are **not** in the tool's `firmware` folder, so they don't appear in its Version list. The tool bundles v51, v56, v60, v61, v63 and v74. If you do want to flash one, drop the files into the tool's `firmware` folder (keep the filenames) and flash the dongle before the headset.
